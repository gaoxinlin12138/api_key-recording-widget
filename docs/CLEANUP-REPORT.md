## 3. 做了什么（七类）

1. **删除从未被调用的界面代码**：`dashboardViewLegacy`、`settingsViewLegacy`、`dashboardViewLegacy2`；
2. **删除失效入口**：仪表盘"快速导入"（入口早已不存在，事件链还留着）；
3. **恢复一个被改版弄丢的功能**：总览页"最近活动"时间线（后端一直在记，界面没显示）；
4. **删除 6 个无调用方的接口**：`/api/health`、`GET keys/{id}`、`balance-history`、`GET settings`、`PATCH|DELETE models/{id}`；
5. **删除无用文件**：设计稿、`app.png`、过期的单文件打包链；
6. **CSS 瘦身**：105 条针对已下线界面的规则 + 21 条被 `display:none !important` 永久隐藏的伪元素规则；
7. **补测试与门禁**：27 个 HTTP 测试（路由 / 鉴权 / 备份恢复 / 错误码）+ CI 两道闸门 + 项目自检脚本。

## 4. 怎么证明没改坏

| 手段 | 覆盖 |
|---|---|
| **55 个自动化测试** | 解析、片段、存储、适配器、路由、鉴权、备份恢复、错误码 |
| **A/B 截图 + 像素差异** | 总览 / 全部 Key / 详情 / 设置 四页；差异必须落在"同一份 CSS 连拍两张"的噪声区间 |
| **对照实验** | 先测出渲染噪声（0.5%–1.5%），再判断改动差异是否真的存在 |
| **接口矩阵实测** | 起真实服务逐个打：删除的必须 404、保留的必须 200 |
| **打包冒烟** | PyInstaller 构建 → 启动 exe → `/api/state` 返回 version=1.3.0、8 平台、36 模型 |

复现命令：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe tools\check_project.py --strict
```

## 5. 过程纪律（为什么没出事）

- **先出清单再动手**：验收清单（5 路由 / 34 接口 / 9 条链路 / 25 条 AC）先定，再改；
- **一批一类问题**：9 个批次，每批独立提交、独立跑测试、独立给验收步骤；
- **不删没有证据的东西**：每条删除都附"全项目 0 引用"的检索结果；
- **动手前先建分支**：所有改动在 `cleanup/v1.2.0-slim`，`main` 一次没碰；
- **高风险动作单独放**：CSS 收敛、安全整改不与其他批次混做。
